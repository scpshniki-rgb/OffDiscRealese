# OffDisc language update

The language selector contains only two supported interface languages:
- Русский
- English

Joke/experimental language options have been removed. Unsupported saved language values are normalized to Russian.

Replace the existing GitHub Pages `index.html` with this folder's `index.html`. Keep your existing `offdisc-config.js` (do not overwrite it with the example), because it contains your deployed account API URL.

English translations cover the interface strings in the localization dictionary and common dynamic labels. Usernames, message contents, server names, channel names, and user-written descriptions are intentionally not translated.
